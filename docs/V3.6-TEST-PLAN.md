# Checklist pengujian OHLI Social v3.6.0 — Swipe untuk membalas

## Android / HP
- [ ] Buka Chat dua akun dan pastikan ada pesan masuk serta pesan keluar.
- [ ] Geser gelembung pesan dari kiri ke kanan; bar “Membalas [nama]” harus muncul.
- [ ] Pastikan pratinjau berisi isi pesan yang benar, bukan pesan tetangga.
- [ ] Ketik balasan dan kirim; pesan harus terkirim, bar balasan hilang, dan balon penerima menampilkan kutipan di atas balasan.
- [ ] Tekan × pada bar balasan; bar hilang dan tidak ada kutipan yang ikut terkirim.
- [ ] Geser dari kanan ke kiri; tidak memicu balasan.
- [ ] Gulir vertikal percakapan; halaman tetap dapat discroll normal.
- [ ] Tekan-tahan pesan; menu aksi lama tetap muncul.
- [ ] Pindah ke chat lain saat bar balasan terbuka; target balasan dibersihkan.
- [ ] Putuskan jaringan saat mengirim; pesan error tampil dan bar balasan tetap tersedia untuk mencoba lagi.

## Desktop
- [ ] Klik kanan pesan tetap membuka menu aksi.
- [ ] Pilih “Balas pesan”; bar kutipan muncul.
- [ ] Kirim balasan dan pastikan kutipan terlihat di kedua sisi.

## Catatan
Swipe dioptimalkan untuk sentuhan kiri-ke-kanan. Desktop tetap memakai menu konteks/tombol Balas karena tidak memiliki gesture sentuh yang sama. Pemeriksaan statis tidak menggantikan pengujian dua akun pada perangkat nyata.
